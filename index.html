FULFILL Fulfill Orders grid — server-side filters, set filters & sort
#8975 ↗
What it does

The Fulfill Orders grid now filters and sorts on the server: every column gets a per-column typed filter (text/number/date), Status and Type get set filters whose checkbox options are fetched live from the server and reflect the other active filters, and the new server-persisted Week Number column is filterable and sortable.

What to look for

Filtering Type to 'PO' reloads the grid server-side and shrinks the row count, the Status filter then only offers statuses that actually exist among PO orders, and clicking Week Number re-sorts via a server round-trip.

#9212 ↗
What it does

The search box above the Fulfill Orders grid now searches server-side across the entire tenant's orders — matching order number, customer name, PO #, salesperson, and ERP id — instead of only filtering the rows already loaded in the grid. Typing debounces 300ms, then the grid purge-refreshes with matches pulled fresh from the server.

Watch a search for the tenant's oldest (lowest) order number — a row never loaded in the initial 100-row block — come back from the server, with the status bar dropping to "viewing 1 of 1 rows".

PRODUCE Space Events CSV importer
#8571 ↗
What it does

Space Events can now be bulk-loaded from a CSV instead of keyed one at a time. From the Space tab on the Production Events page, a new Import button opens a guided 6-step wizard: upload your file (a downloadable template is provided), preview the rows, then two validation passes — format checks (required fields, positive-integer durations, duplicate names) and data checks that match each row's CategoryCode, TypeCode, and Trigger against the tenant's existing space categories, space types, and triggers. Rows with unresolvable references are flagged and skipped; everything valid imports as a new Space Event with its detail already wired to the right category, type, and trigger.

What to look for

The stepper advancing through all six stages on a 2-row CSV: the green 'Format Validation Successful' alert, the 'Ready to import: 2 valid, 0 errors, 0 warnings' toast, the Import Preview grid showing both rows as 'valid', and the 'Import Successful' results screen with the '2 Space Events Imported' chip. Then the payoff: back on the Space tab, the two new events appear in the sidebar, and opening one shows its detail row with real resolved references — Space Category SP-4IN, Space Type Floor, Trigger 'At Start', Duration 14 — proving the CSV codes were matched to live entities, not just stored as text.
